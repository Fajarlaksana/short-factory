# Music library

The studio pipeline picks background music from this folder, by mood.
Put royalty-free tracks you are allowed to use on YouTube in these subfolders:

```
music_library/
  documentary/   calm, cinematic, curious (default for most business videos)
  corporate/     clean, modern, positive
  tension/       suspense, "the dark side of..." stories
  upbeat/        energetic success stories
  lofi/          relaxed explainers
```

Good free sources that are safe for monetized YouTube:
- YouTube Studio > Audio Library (filter: "No attribution required")
- Pixabay Music (pixabay.com/music)

Tips: instrumental only, no vocals; 10 to 20 tracks across moods is enough.
If a mood folder is empty, any track in the library is used. If the library is empty,
videos are rendered without music.
